📑 အညွှန်း : နိဒါန်း Selector အရောင်/ဖောင့် Box Model Flexbox Grid Position Animation Responsive

🎨 ၁။ CSS ဆိုတာ ဘာလဲ။ (အခြေခံသဘောတရား)

CSS ဆိုတာ Cascading Style Sheets ရဲ့ အတိုကောက်ပါ။ ဝက်ဘ်စာမျက်နှာရဲ့ အသွင်အပြင် (presentation) ကို သတ်မှတ်ပေးတဲ့ ဘာသာစကားဖြစ်ပါတယ်။

  • HTML = အရိုးစု (အိမ်ရဲ့ ဘောင်ခတ်မှု)
  • CSS = အလှဆင်ခြင်း (ဆေးသုတ်၊ ပရိဘောဂ၊ ကုလားကာ)
  • JavaScript = အလုပ်လုပ်ပုံ (လျှပ်စစ်၊ ရေ၊ အလိုအလျောက်စနစ်)

CSS ကို နည်း ၃ မျိုးဖြင့် ထည့်သွင်းနိုင်ပါတယ် −

  1. Inline CSS — HTML element ထဲတွင် style attribute ဖြင့် ထည့်ခြင်း
  2. Internal CSS — <head> ထဲတွင် <style> tag ဖြင့် ထည့်ခြင်း
  3. External CSS — သီးခြား .css ဖိုင်ခွဲထုတ်ပြီး <link> ဖြင့် ချိတ်ခြင်း (အကောင်းဆုံး)
<!-- Inline CSS -->
<h1 style="color: blue;">မင်္ဂလာပါ</h1>

<!-- Internal CSS (in <head>) -->
<style>
  h1 { color: green; }
</style>

<!-- External CSS -->
<link rel="stylesheet" href="style.css">
📌 အကြံပြု: External CSS ကို အသုံးများဆုံးဖြစ်ပြီး ပြုပြင်ထိန်းသိမ်းရလွယ်ကူတယ်။

🎯 ၂။ Selector များ (ဘယ် element ကို ပြင်မလဲ)

Selector ဆိုတာ CSS စည်းမျဉ်းတွေ ဘယ် HTML element ပေါ်မှာ သက်ရောက်မယ်ဆိုတာ သတ်မှတ်ပေးတဲ့အပိုင်းပါ။

🔹 အခြေခံ Selector

  • element — tag name (ဥပမာ h1, p)
  • .class — class name (ဥပမာ .highlight)
  • #id — id name (ဥပမာ #header)
  • * — အားလုံး (universal)

🔸 ပေါင်းစပ် Selector

  • div p — descendant (အတွင်းမှာ ရှိသမျှ)
  • div > p — child (တိုက်ရိုက်သား)
  • h1 + p — adjacent sibling (ကပ်လျက်)
  • h1 ~ p — general sibling (နောက်လိုက်အားလုံး)

🎨 Pseudo-classes & Pseudo-elements

  • :hover — မောက်စ်တင်ထားချိန်
  • :focus — focus ရောက်ချိန် (input)
  • :nth-child(n) — သတ်မှတ်နေရာ၏ သားသမီး
  • ::before / ::after — element ရှေ့/နောက်တွင် ထည့်သွင်းခြင်း
/* Element selector */
h1 { color: #064e3a; }

/* Class selector */
.highlight { background: yellow; }

/* ID selector */
#main-title { font-size: 2.5rem; }

/* Pseudo-class */
a:hover { color: #0a7c5e; }

/* Pseudo-element */
p::first-letter { font-size: 2em; }
💡 အရေးကြီး: Class ကို အများဆုံးသုံးပြီး ID ကို တစ်မျက်နှာလျှင် တစ်ကြိမ်သာ သုံးသင့်တယ်။

🌈 ၃။ အရောင် (Color) နှင့် ဖောင့် (Font)

🎨 အရောင်သတ်မှတ်နည်းများ

  • color: red; — ကြိုသတ်မှတ်ထားသောအမည်
  • color: #0a7c5e; — Hex code
  • color: rgb(10, 124, 94); — RGB
  • color: rgba(10, 124, 94, 0.7); — RGB + alpha (ပွင့်လင်းမှု)
  • color: hsl(160, 85%, 26%); — HSL
ဤသည်မှာ အရောင်ဥပမာ (background: #d4edda)

🔤 ဖောင့် (Font) သတ်မှတ်ခြင်း

  • font-family — ဖောင့်အမျိုးအစား (ဥပမာ Arial, Pyidaungsu)
  • font-size — အရွယ်အစား (px, rem, em, %)
  • font-weight — အထူ (bold, 400, 700)
  • font-style — စောင်း (italic, normal)
  • text-align — စာသားနေရာချထားမှု (left, center, right)
  • text-decoration — မျဉ်းသတ်ခြင်း (underline, none)
ဤသည်မှာ ဖောင့်ဥပမာ (Georgia, 1.2rem)
p {
  color: #1d5a44;
  font-family: 'Pyidaungsu', 'Segoe UI', sans-serif;
  font-size: 1.1rem;
  font-weight: 400;
  text-align: justify;
  line-height: 1.8;
}

📦 ၄။ Box Model (အကွက်သဘောတရား)

HTML element တိုင်းကို စတုဂံသေတ္တာ (box) တစ်ခုအနေဖြင့် မြင်နိုင်ပါတယ်။ Box Model မှာ −

  • Content — စာသား/ပုံ အမှန်တကယ်ပါဝင်သည့်နေရာ
  • Padding — Content နှင့် Border ကြားအကွာအဝေး (အတွင်းခံ)
  • Border — အနားသတ်မျဉ်း
  • Margin — အခြား element များနှင့် ခြားသည့်အကွာအဝေး (အပြင်ခံ)
.box-example {
  width: 300px;
  padding: 20px;          /* အတွင်းခံ */
  border: 3px solid #0a7c5e;
  margin: 16px auto;        /* အပြင်ခံ + အလယ်ချိန် */
  border-radius: 16px;   /* ထောင့်ဝိုင်းခြင်း */
  box-sizing: border-box; /* width ထဲ padding+border ပါဝင်စေရန် */
}
ဤသည်မှာ Box Model ဥပမာ — Border + Padding + Margin
Shadow (အရိပ်) ပါသော အကွက်
📌 အရေးကြီး: box-sizing: border-box; ကို အားလုံးအတွက် သတ်မှတ်ထားခြင်းဖြင့် အရွယ်အစားတွက်ရလွယ်ကူစေတယ်။

🧘 ၅။ Flexbox (ပြောင်းလွယ်ပြင်လွယ် Layout)

Flexbox သည် container အတွင်းရှိ items များကို ဘေးတိုက်/ဒေါင်လိုက် လိုသလိုစီစဉ်ရန် အားကောင်းသော layout model ဖြစ်တယ်။

Container Properties

  • display: flex; — flex container ဖြစ်စေရန်
  • flex-direction — row / column / row-reverse
  • justify-content — main axis ပေါ် နေရာချ (center, space-between, etc)
  • align-items — cross axis ပေါ် နေရာချ (center, stretch, etc)
  • flex-wrap — wrap / nowrap
  • gap — items ကြားအကွာအဝေး

Item Properties

  • flex-grow — နေရာလွတ်ကို ဘယ်လောက်ယူမည်
  • flex-shrink — ကျုံ့နိုင်မှု
  • flex-basis — အခြေခံအရွယ်
  • align-self — ကိုယ်ပိုင် align သတ်မှတ်
  • order — အစဉ်ပြောင်းရန်
Item 1 Item 2 Item 3 Item 4

⬆️ Flexbox ဖြင့် ဘေးတိုက်စီထားသော items

.flex-container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  flex-wrap: wrap;
  gap: 16px;
}

.flex-item {
  flex: 1 1 150px; /* grow shrink basis */
  padding: 12px;
  background: #e2f0ea;
}

📐 ၆။ CSS Grid (ဇယားကွက် Layout)

Grid သည် ၂ ဖက်မြင် (rows နှင့် columns) ဖြင့် layout ကိုတည်ဆောက်ရန် အစွမ်းထက်ဆုံး CSS module ဖြစ်တယ်။

  • display: grid; — grid container ဖြစ်စေရန်
  • grid-template-columns — column အရေအတွက်နှင့်အရွယ်
  • grid-template-rows — row အရေအတွက်နှင့်အရွယ်
  • gap — grid အကွက်များကြားအကွာ
  • grid-column / grid-row — အကွက်တစ်ခုစီ၏ နေရာသတ်မှတ်
.grid-container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr; /* 3 columns */
  grid-template-rows: auto 200px;
  gap: 16px;
}

.grid-item {
  background: #f0f7f3;
  padding: 16px;
  border-radius: 12px;
}

.item-large {
  grid-column: 1 / 3; /* column 1 မှ 3 အထိ */
}
📌 နှိုင်းယှဉ်ချက်: Flexbox က ၁ ဖက်မြင် (row/column) အတွက် သင့်တော်ပြီး Grid က ၂ ဖက်မြင် (row + column) အတွက် အကောင်းဆုံးဖြစ်တယ်။

📍 ၇။ Position (နေရာချထားခြင်း)

position property က element တစ်ခုကို ပုံမှန်စီးဆင်းမှုမှ ထုတ်ပြီး နေရာချရန် သုံးတယ်။

  • static — ပုံမှန် (မူလ)
  • relative — ပုံမှန်နေရာမှ ရွှေ့ခြင်း
  • absolute — အနီးဆုံး relative/absolute ပေါ်မူတည်၍ နေရာချ
  • fixed — viewport ပေါ်တွင် သတ်မှတ်နေရာ (scroll လုပ်လည်းမပြောင်း)
  • sticky — scroll လုပ်သည့်အခါ သတ်မှတ်နေရာတွင် ကပ်နေခြင်း

🔹 offset properties

top, right, bottom, left ဖြင့် အကွာအဝေးသတ်မှတ်နိုင်တယ်။

z-index ဖြင့် အထက်အောက်အဆင့်သတ်မှတ်နိုင်တယ်။

.relative-box {
  position: relative;
  top: 10px;
  left: 20px;
}

.absolute-box {
  position: absolute;
  top: 0;
  right: 0;
}

.fixed-header {
  position: fixed;
  top: 0;
  width: 100%;
  z-index: 100;
}

✨ ၈။ Animation & Transition

🔄 Transition

အခြေအနေပြောင်းလဲမှုကို ချောမွေ့စေရန် −

  • transition-property — ဘယ် property ကို
  • transition-duration — ကြာချိန်
  • transition-timing-function — အရှိန် (ease, linear, etc)

🎬 Keyframe Animation

@keyframes ဖြင့် အဆင့်ဆင့်သတ်မှတ်ပြီး animation property ဖြင့် ခေါ်သုံးတယ်။

/* Transition */
.btn {
  background: #0a7c5e;
  transition: background 0.3s ease, transform 0.2s;
}
.btn:hover {
  background: #064e3a;
  transform: scale(1.05);
}

/* Keyframe Animation */
@keyframes slideIn {
  0% { transform: translateX(-100px); opacity: 0; }
  100% { transform: translateX(0); opacity: 1; }
}
.animated {
  animation: slideIn 0.8s ease-out;
}
🖱️ မောက်စ်တင်ကြည့်ပါ (Transition)

📱 ၉။ Responsive Design (Media Queries)

Media Queries ဖြင့် မျက်နှာပြင်အရွယ်အစားအလိုက် CSS ကိုပြောင်းလဲနိုင်တယ်။

  • @media (max-width: 768px) { ... } — ဖုန်းအရွယ်
  • @media (min-width: 769px) and (max-width: 1024px) { ... } — တက်ဘလက်
  • @media (min-width: 1025px) { ... } — ဒက်စ်တော့
/* Default (desktop) */
.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 20px;
}

/* Tablet */
@media (max-width: 1024px) {
  .container {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Mobile */
@media (max-width: 600px) {
  .container {
    grid-template-columns: 1fr;
  }
  body {
    padding: 12px;
  }
}
📌 အရေးကြီး: meta viewport ကို HTML တွင်ထည့်ရန် မမေ့ပါနှင့်။
